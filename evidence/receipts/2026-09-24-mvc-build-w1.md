## Findings

1. **F-1 DOCKERFILE_STALE_VS_SERVED_APP.** `petcare_api/Dockerfile` copies only
   `main.py` and `routers/`, but `main.py` imports `roles`, `prescriptions`,
   `prescription_documents`, `repositories`, `tenant_membership`,
   `audit_repository` and others from `petcare_api/`. An image built from it
   would fail at import. Measured by reading; not built here. Deploy scope,
   outside W1.
2. **F-2 UNBOUND_SERVED_ROUTES=15.** Served domain routes bound to no FR:
   appointments (2), consultations + notes (4), admin tenant membership (2),
   audit (4), governance status, health, ready. The BRD FR set has no
   appointment-booking FR; consultations are not video (FR-06 stays ABSENT).
3. **F-3 IN_MEMORY_AND_CLIENT_ACTOR_ON_UNBOUND_ROUTES.** Appointments,
   consultation sessions and notes are module-level dicts (`main.py:185-187`)
   and take the audit actor from `x_actor_id` (`main.py:530,566,600,638,669,708`).
   `GET /api/appointments/{id}` and `GET /api/consultations/{id}` read by id
   with no tenant predicate. Security track, not W1.
4. **F-4 FR-02 SERVED_ROUTE_UNTESTED.** `POST /api/pets` has no test anywhere;
   its store is a node-local JSON file (`uphr/service.py:44`).
5. **F-5 TAXONOMY_UI_ONLY_GAP.** FR-09 is a UI property; the five-state
   taxonomy measures served API routes and pytest collection only, so a
   UI-only FR can never exceed BUILT_UNWIRED. Recorded, not worked around.
6. **F-6 LEGACY_UI_TREE.** `petcare-web/` (hyphen) is tracked but has no
   deployment config; `petcare_web/` is the deployed UI.
7. **F-7 AUTH_EVENTS_OUTSIDE_AUDIT_CHAIN** (pre-existing, `routers/auth.py:265`)
   — FR-01 `audit_actor_source=NONE`.
8. **F-8 KNOWN_LIMIT.** REACHABLE_TESTED does not prove bound tests exercise
   the served app. FR-01/14/27 bound tests do drive `main.app`
   (`test_option_a_workflow.py:3`), but the checker verifies collection only.
9. **F-9 PRE-EXISTING (unchanged, not staged).** 4 unsealed receipts under
   `evidence/receipts/2026-09-07-*`; `.claude/` and `.claude-flow/` tooling dirs.
